## 📖 نظرة عامة (Overview)

منصة رقمية متكاملة حديثة أعيد تصميمها وهندستها كلياً وفق أعلى معايير التصميم والتفاعل الرقمي المؤسسي للقطاع غير الربحي السعودي، مع الحفاظ الصارم على **الهوية البصرية المعتمدة (Brand Identity)** لجمعية البر بالجله وتبراك، وتضم لوحة تحكم إدارية شاملة **(Full Admin CMS Dashboard)** للتحكم بجميع صفحات ومحتويات المنصة وأرقام الأثر التنموي.

---

## ✨ المميزات المعمارية والوظيفية (Key Features)

### 1. 🏠 الصفحة الرئيسية ولوحة الأثر الإنساني (Impact-First Experience)
- **واجهة العرض القيادية (Hero):** صورة جماعية لكوادر الجمعية ومبنى المقر الرسمي، مع بطاقات وصول سريع.
- **عرض الأثر المتوازن (Human Scale + Financial Transparency):** يتصدر عدد الحالات والأسر والإنسان المشهد الإحصائي (+3,750 حالة سنوياً / +18,500 تراكمياً لـ 5 سنوات)، مصحوبة بالوسوم المالية للشفافية المعتمدة.
- **تبديل لحظي سلس:** استعراض مؤشرات أثر عام 2025 مقابل المؤشرات التراكمية لآخر خمس سنوات.
- **قطاعات الصرف الاستراتيجية الـ 8:** بطاقات تفاعلية توضح عدد الحالات المستفيدة، نوع الدعم العيني والغذائي، والمبلغ المنصرف.

### 2. 📱 تجربة الهواتف والأجهزة اللوحية (Mobile & Tablet Optimized - Native App UX)
- **شريط تنقل سفلي لمسي (Bottom Navigation Bar):** مخصص للهواتف الذكية مع وصول فوري للرئيسية، الأثر، المتجر، والبرامج.
- **نافذة الأقسام الشاملة (Action Sheet Modal):** تنبثق بسلاسة من أسفل الشاشة لعرض شبكة الأقسام بروابط لمسية مريحة وزر واتساب مباشر.
- **توافق تام مع معايير شاشات اللمس:** ارتفاعات تفاعلية `min-height: 46px` مع أحجام خطوط `16px` تمنع التكبير التلقائي المزعج على هواتف iPhone.

### 3. ⚙️ لوحة التحكم الإدارية الشاملة (Full Admin CMS Dashboard)
- **الرابط المباشر:** `admin.html`
- **تحكم 100% بكافة أقسام المنصة:**
  - تعديل نصوص وصور الواجهة الرئيسية، أرقام الأثر التراكمي لـ 5 سنوات وعام 2025.
  - إدارة أعضاء مجلس الإدارة، الجمعية العمومية، واللجان التنفيذية.
  - إضافة وتعديل لوائح الحوكمة العشر، وإدارة أرشيف القوائم والتقارير المالية والسنوية.
  - إدارة البرامج الاستراتيجية والمشاريع الميدانية، وبطاقات المتجر الإلكتروني.
  - حفظ وتزامن فوري عبر `localStorage` مع إمكانية تصدير واستيراد النسخ الاحتياطية (JSON Backup).
  - قائمة جانبية ذكية (Off-Canvas Drawer) متجاوبة مع الهواتف والأجهزة اللوحية.
  - جداول بيانات متجاوبة (`admin-table-responsive`) قابلة للتمرير الأفقي اللمسي دون تكسر التنسيق.

### 4. 🧮 الأدوات الرقمية والحاسبات التفاعلية
- **حاسبة الزكاة الشرعية الشاملة:** تحسب زكاة السيولة النقدية، الذهب بمختلف عياراته (24، 21، 18 قيراط وفق أسعار الجرام اللحظية)، والفضة مع بيان بلوغ النصاب الشرعي ومقدار الزكاة الواجبة.
- **حاسبة أثر التبرع التفاعلية:** شريط تفاعلي يتيح للمتبرع معرفة الأثر الحقيقي لتبرعه (عدد الوجبات، صهاريج السقيا، ساعات التدريب، كسوة الأيتام).
- **بوابة التبرع بالأفكار والوقت التطوعي:** نموذج رقمي لاستقبال مبادرات المتطوعين وربطها بإدارة الجمعية.

### 5. 🛡️ الحوكمة والشفافية النظامية
- **مستكشف الحوكمة التفاعلي (Governance Explorer Modal):** نافذة تصفح مخصصة للوائح والسياسات العشر المعتمدة من المركز الوطني للقطاع غير الربحي مع البحث المباشر في الأبواب والمواد.
- **التقارير المالية المدققة:** أرشيف القوائم المالية المستقلة والتقارير السنوية.

### 6. 🎨 الأيقونات والرسومات المتجهية النظيفة (Zero-Emoji Invariant)
- اعتماد مكتبة أيقونات `SVG Stroke Icons` عالية النقاء والدقة لجميع عناصر الواجهة ولوحة التحكم، خالية تماماً من رموز الإيموجي العشوائية بما يعكس الهيبة الرسمية والاحترافية العالية.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Frontend:** Vanilla HTML5, Modern Responsive CSS3 (CSS Grid & Flexbox, Custom Properties), Modern JavaScript (ES6+ SPA Router).
- **Icons:** Pure Scalable Vector Graphics (SVG).
- **Data & State Management:** Dynamic `data.js` synced bidirectionally with `LocalStorage`.
- **Zero Heavy Dependencies:** فائق السرعة وخفيف الوزن (No heavy external frameworks / 100% Offline Compatible).
- **Hosting:** Static Flat-Ready deployment with GitHub Pages & `.nojekyll`.

## 🚀 التشغيل المحلي (Local Development)

لتشغيل المنصة محلياً على جهازك:

```bash

cd "website جديد"

# 2. تشغيل خادم محلي خفيف عبر Python
python -m http.server 8000

# 3. فتح المتصفح على:
# الموقع الرئيسي: http://localhost:8000/index.html
# لوحة التحكم: http://localhost:8000/admin.html
```
